# Local logo files

Used only when `logos.source` is `"local"` in `src/config/gameConfig.js`.

Each file must be named after the entry's `id` in `src/data/logoDatabase.js`:
`github.svg`, `linux.svg`, `nodedotjs.svg`, ...

Where to get logos: the Simple Icons package (https://simpleicons.org), or official brand/press kits.
Download a copy of the logo you need, rename it to `<id>.svg`, and put it in this folder.
