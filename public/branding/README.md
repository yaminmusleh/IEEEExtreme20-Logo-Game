# Branding assets

Put only APPROVED IEEE / IEEE Computer Society / IEEE Xtreme 20 logo files here
(obtain them from your organization's brand guidelines or your IEEE contact).

Then set the paths in `src/config/gameConfig.js`:

    branding: {
      eventLogo: "/branding/xtreme-20.png",
      organizerLogo: "/branding/computer-society.png",
    }

Until then the app shows a neutral text placeholder.
